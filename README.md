# Kilo Core
A new browser based on Brave browser

## What new?
Added functionality to access our fully anonymous domain name system. Click [here](https://github.com/left-TTC/web3-domain-registrar) to learn more. 

## Brave Core
Brave Core is a set of changes, APIs, and scripts used for customizing Chromium to make the Brave browser. Please also check https://github.com/brave/brave-browser

Follow [@brave](https://twitter.com/brave) on Twitter for important announcements.
